## Модуль generators
Содержит функции для эффективной обработки данных транзакций:
1. `filter_by_currency` — фильтрует транзакции по валюте (возвращает итератор).
2. `transaction_descriptions` — выдает описание каждой операции.
3. `card_number_generator` — генерирует номера карт в формате `XXXX XXXX XXXX XXXX`.

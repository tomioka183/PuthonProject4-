# Проект "Банковские операции"
Проект для маскировки данных, фильтрации и генерации номеров карт.

## Основные модули:
- `masks`: маскировка карт и счетов.
- `widget`: работа с датами и картами.
- `generators`: эффективная обработка данных.

## Тестирование:
Запуск: `pytest`
Покрытие: `pytest --cov=src --cov-report=html`

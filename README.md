## Описание новых инструментов

### Декоратор `log`
В проекте реализован декоратор `@log`, который предназначен для автоматического логирования работы функций.
- **Логирование успеха:** записывает имя функции и статус `ok` при успешном выполнении.
- **Логирование ошибок:** в случае сбоя записывает имя функции, тип возникшей ошибки и входные параметры, с которыми была вызвана функция.
- **Гибкость:** декоратор может выводить логи как в консоль (по умолчанию), так и в файл (если указан аргумент `filename`).

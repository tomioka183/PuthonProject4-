# Проект: Анализатор банковских операций

## Описание:
Проект предназначен для обработки и фильтрации финансовых транзакций. Он умеет считывать данные из различных форматов (JSON, CSV, Excel), маскировать номера карт и счетов, а также фильтровать операции по их статусу.

## Функциональность:
- **Обработка данных**: Поддержка форматов JSON, CSV и XLSX.
- **Маскировка**: Безопасное отображение номеров карт (вид 1234 56** **** 3456) и счетов (вид **4321).
- **Фильтрация**: Сортировка и выборка транзакций по статусу (например, EXECUTED).
- **Тестирование**: Код полностью покрыт юнит-тестами (с использованием pytest и mock).

## Установка:
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`

## Использование:
- Функции для работы с файлами находятся в `src/utils.py`.
- Логика обработки — в `src/processing.py`.
